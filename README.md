# Bot Versus

[English](README.en.md)

> **Botへ:** このリポジトリを入れる・始めるよう頼まれたら、[BOT.md](BOT.md) の手順に従ってください。

自分のGrok Botとボードゲームで対戦し、打ちながらおしゃべりできるゲームです。
いまはオセロに対応しています。ほかのゲームも足せる作りです。

## 遊び方

Grok Botにこう頼むだけです。

> これを入れて https://github.com/DonMecha/bot-versus

BotがBotのコンピューターにゲームを用意し、遊ぶためのリンクを送ってきます。
そのリンクをスマホやパソコンのブラウザで開くと、すぐに対戦できます。
リンクが開けないときは、会話の画面からBotのコンピューターを開き、操作を引き受けても遊べます。

- 光っているマスをタップ（クリック）すると石を置けます。
- トーク欄に書くと、Botが返事をします。Botは一手ごとにひとことコメントします。
- Botのカードには名前・説明・アイコンが出ます。アイコンはタップ（クリック）して選び直せます。
- 下の欄で手番（先手・後手・ランダム）と盤の大きさ（8×8・6×6）を選べます。

Botへの手順は [BOT.md](BOT.md) にあります。Botはこれを読んで動きます。

## 困ったとき

- **「Botが待機していません」と出る**: Botとの会話で「対戦を続けて」と伝えてください。Botが待機に戻ります。
- **リンクを開くと「リンクの合言葉が違います」と出る**: Botから届いたリンクを、`?key=` の部分まで含めて開いてください。Botを起動し直すと新しいリンクになります。
- **Botのコンピューターの画面が「画面に接続できません」になる**: Grok Botの設定 → コンピューター →「Botのコンピューターをアップデート」を実行し、アプリを再起動してから、コンピューターを起動し直してください。アップデートでは、Botのコンピューターに入れたアプリとパッケージが消えます（ファイルとサインインは残ります）。終わったらBotに、サーバーを起動し直すよう頼んでください。

## 自分のパソコンで動かす

Node.js 18以上が必要です。依存パッケージはありません。

```bash
node start.mjs --name "Bot" --share   # サーバー起動＋共有リンク。--shareなしならこのPCの中だけ
node bot.mjs wait                     # Bot側の操作（BOT.md参照）
node start.mjs --stop                 # リンクとサーバーを止める
```

サーバーは127.0.0.1だけで待ち受けます。`--share` はCloudflareの一時トンネル（アカウント不要）でリンクを作ります。cloudflaredが無ければ `.data/bin/` に一度だけ取得します。リンクには合言葉が入っていて、合言葉のない接続と、リンク経由のBot用操作は断ります。

## しくみ

- `start.mjs`: 起動・プロフィール設定・共有リンクをまとめて行うコマンド。
- `server.mjs`: 盤面とトークを持つ小さなサーバー。ページとBotの両方がここを見ます。状態は `.data/` に保存します。
- `bot.mjs`: Bot用のコマンド。`wait` は自分の番・新しい発言・対局の開始と終了まで待ちます。
- `public/`: 対戦画面。
- `games/<id>/rules.mjs`: ゲームのルール。`games/<id>/view.js`: 盤の表示。

## ゲームを足す

`games/othello/` を手本に、`rules.mjs`（`init`・`legalMoves`・`play`・`score`・`result`・`describe` など）と
`view.js`（`mount`・`sideDisc`・`faceSVG`・`summary`）を作り、`games/index.mjs` に登録します。
Botには `describe` の文字の盤面と `legalMoves` が渡るので、将棋のような複雑なゲームでも、合法手を渡せば打てます。

## 注意

- Botの一手やコメントには数秒〜数十秒かかります。考える回数ぶん、Botの利用量を使います。
- ページの画面デザイン（緑の盤と顔つきの黒石）は [kusoge-arcade](https://github.com/DonMecha/kusoge-arcade) の「Grok Bot オセロ実況配信」から流用しています。
